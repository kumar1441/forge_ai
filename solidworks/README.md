# Forge for SolidWorks

The SolidWorks add-in — a chat panel inside SolidWorks that turns plain English into verified parametric edits.

```
dotnet build Forge.SolidWorks.csproj -c Release -p:Platform=x64
Register-Forge.bat        (right-click → Run as administrator)
```
